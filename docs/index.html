🎲 Codenames Card Generator

A high-performance Laravel engine for generating printable card boards. Optimized for A4 duplex printing with zero-margin precision.

borschcode.github.io/code-names-pictures-prepare

🖨 Printable PDF

Fixed 3×4 grid alignment. Perfectly mirrored for double-sided production.

🧩 Image Assets

Pre-rendered square card geometry. No runtime latency or API dependencies.

⚙️ CLI Core

Artisan-powered batch processing for automated deck generation.

Available Commands

php artisan app:generate-code-names-pdf

Generate a printable A4 PDF with Code Names pictures arranged in a 3×4 grid. → storage/code_names_pdf/code_names.pdf

php artisan app:generate-code-names-words-pdf {file}

Generate CodeNames PDF with larger mirrored font, large rotated icons, and wheel circle style. → storage/code_names_pdf/code_names_words.pdf

php artisan app:grayscale-code-names-images

Convert Code Names images from color to grayscale — ideal for black-and-white printing.

php artisan app:resize-code-names-images

Resize Code Names images to a selected target size for optimal print quality.

File Structure

Input
storage/code_names/ Source PNG card images — read by all three image commands
storage/icons/ Icon PNGs used as compass/wheel decorations in the words PDF
storage/words.txt Word list (one word per line) — passed as {file} argument to the words command
Output
storage/code_names_pdf/ Generated PDFs (code_names.pdf, code_names_words.pdf)
storage/code_names_grayscale/ Grayscale copies of all card images
storage/code_names_resized/ Resized copies of all card images
